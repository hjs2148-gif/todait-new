# Todait 웹앱 결정 사항

마지막 정리: 2026-11-22. 대화가 압축되거나 새 세션에서 이어갈 때 이 파일부터 읽는다.
**지금 상태는 맨 아래 10번(구현 현황)과 7번(다음 할 일)을 먼저 본다.** 2·3·6-1번은 디자인 탐색 당시 기록이다.

## 1. 프로젝트 개요

- 원본: Todait 안드로이드 앱 0.30.44 (APK). 순수 네이티브 앱이라 코드 재사용 불가 → 분석 후 웹앱으로 재구현.
- 용도: **개인용, 폰에서만** 사용. 서버 없음, 데이터는 브라우저 IndexedDB.
- 스택: React 18 + TypeScript + Vite, PWA(서비스 워커, 홈 화면 설치).
- 배포: GitHub Pages — https://hjs2148-gif.github.io/todait-new/
  - 저장소 `hjs2148-gif/todait-new`, `main` 푸시 시 `.github/workflows/deploy.yml`로 자동 배포.
  - 커밋 작성자는 GitHub noreply 주소 사용.
- 현재 배포된 앱은 **새 디자인**(2026-11-22 배포, 커밋 `21e407b`·`55183fc`·`af4a589`). 자세한 현황은 10번.
- 배포가 "No artifacts named github-pages" 로 실패하던 문제는 2026-11-24에 고침: `deploy.yml`을 빌드·배포 두 작업으로 나누고(공식 예제 방식) Pages 도구를 v5로 올림. 같은 작업 안에서 업로드 직후 배포하면 아티팩트를 못 찾았다. 그래도 실패하면 Actions에서 Re-run.

## 2. 구현된 기능 (첫 버전 기준, 기록용 — 지금은 10번 참고)

- 계획 4종: 분량(범위/총량), 매일 반복, 시간, 체크. 반복은 요일마다 또는 N일마다.
- 분량 자동 배분: 원본 `ByAmountTaskLogic`을 옮김(`src/logic.ts`). 남은 분량을 남은 공부일로 올림 분배, 밀리면 재분배, 보충 요일, 날짜별 분량 변경/쉬는 날. 테스트 `src/logic.test.ts`.
- 오늘 화면, 분량 입력, 스톱워치(시작 시각 기준, 화면 꺼짐 방지), 캘린더, 통계, 공부일기(사진 첨부), D-day, 카테고리 색, 알림(앱이 살아 있을 때만), 백업 내보내기/불러오기, 다크 모드는 아직 없음.

## 4. 확정된 기능 방향 (진도 중심)

- **탭**: 오늘 · 진도 · 캘린더 · 통계 · 더보기. 일기 탭은 없앰(분량 입력에 한 줄 메모로 대체 예정).
- **오늘**: 맨 위 "오늘 남은 공부 약 ○시간 ○분"(공부 속도로 계산) + 공부한 시간 막대 + "○단원 이어서 하기" 버튼. 계획은 밀린 것부터, 단원 이름·쪽 범위·남은 양·"○쪽 밀림/예정대로" 표시. 완료는 한 줄로 접기. D-day·성취율·연속일은 작게.
- **새 계획**: 나누는 방식 5종(분량·**목차**·매일·시간·체크). 목차는 단원 이름+쪽 범위 입력 또는 붙여넣기. "단원 순서대로 / 하루 쪽 수 일정하게" 선택. 미리보기에 단원별 날짜.
- **진도 탭**: 전체 진도와 **예정 위치를 같은 막대에 세로선으로**. 계획마다 단원별로 나뉜 막대, 지금/예정 위치, 예상 완료일. 복습할 때가 된 단원(이해도 낮음, 완료 후 시간 경과).
- **진도 자세히**: 지금 속도 vs 필요 속도, 단원 지도(완료일·걸린 날·이해도·예정 날짜).
- **통계**: 대시보드(이번 주 공부 시간·지난주 대비, 지표 카드 4개, 이번 주에 이룬 것, 계획별 진도, 공부 습관, 과목 비중) → 누르면 자세한 통계(요일별 막대, 집중 시간대 히트맵, 도넛, 성취율 추이, 공부 잔디, 집중 기록, 완료 예측).
- **이해도**: 단원 완료 시 상·중·하 기록 → 복습 추천.
- 모든 통계는 기존 데이터(스톱워치 기록 `histories`, 날짜별 분량 `recs`)로 계산 가능. 진도 탭·목차 계획·이해도·복습·통계 계산은 **새로 구현해야 함**.

## 5. 디자인 원칙 (지금까지 확인된 취향)

- **설명은 쉽게 (2026-11-24 요청)**: 결과를 알려 줄 때 전문 용어(아티팩트, FLIP, 커밋 해시, 워크플로 등)를 쓰지 않고 쉬운 말로. 무엇이 바뀌었는지 → 폰에서 어떻게 보이는지 → 내가 할 일 순서로 짧게.

- 색이 **면 전체를 덮으면 촌스럽다**. 색은 작게, 뜻이 있는 곳에만.
- 회색만 있으면 **삭막하다**. 과목별 표정(색 아이콘·색 제목)은 필요.
- 연한 색 칩 + 링 + 둥근 카드의 조합은 **AI 티가 난다**. 실제 앱의 관습을 근거로 디자인할 것.
- 다크 모드 필요(밤에 공부).
- 시인성: 본문 15~16px, 보조 13px, 캡션(그래프 축·범례·단원 번호·작은 설명) 12px. **12px 미만 금지.** 모든 글자 대비 4.5:1 이상, 아이콘·막대 3:1 이상. 색만으로 상태를 말하지 않는다.
- 폭: 390px 기준으로 그리고 **320px에서 넘침 없음**을 확인(2026-11-21 전 화면 점검). 긴 이름은 말줄임, 좁으면 줄바꿈 허용.
- **계획 분류는 앱 전체에서 5가지**: 책(책·문제집) · 인강 · 시간 · 습관 · 할 일. 데이터의 '계획 종류'와 같다. 화면은 이 중 필요한 것만 보여 준다(진도 탭은 끝이 있는 책·인강만).
- 한글 글꼴은 Pretendard(캔버스에서는 불러올 수 없어 Noto Sans KR로 보임).
- (오늘 탭 탐색에서 확인) 숫자·표·얇은 선만으로 절제하면 "별로". **시각적 인포그래픽**(도넛, 반원 게이지, 막대, 칸)으로 직관적으로 보여 줄 것. 원형 그래프도 OK.
- 계획 유형마다 **목적에 맞는 다른 진행 그림**(책=쪽 칸+리본 책갈피, 문제집=문항 동그라미, 인강=재생 바+강의 칸, 시간=10분 블록, 습관=달력 잔디, 할 일=체크박스). 카드 뼈대(첫 줄·그림·맨 아래 요약)는 통일.
- 팔레트: 따뜻한 종이색 바탕(#f3f0ea), 먹색 글자, 과목색은 작게, 책갈피 황토색(#b0750f), 경고 빨강(#b03a2a). 다크는 따뜻한 검정(#121110).
- 캔버스 렌더 확인: `.claude/launch.json`의 `design-preview`(스크래치패드 serve.js) + `render.js`로 정적 HTML을 만들어 브라우저 패널에서 확인.

## 5-1. 목적 검토 후 원칙 (2026-11-21)

앱 목적 = 진도 **파악** · **기록** · **동기부여**. 잘 되는 날이 아니라 **무너지는 날**에 버티게 설계한다.

1. **시작은 한 번에.** 오늘 탭 하단 탭 위(엄지 영역)에 "다음 공부 · 수학의 정석 75쪽부터 ▶ 시작" 바. 시작하면 같은 자리에서 스톱워치 미니 바로 바뀜. 전체 탭 계획 행마다 ▶(할 일은 체크 상자).
2. **%에는 늘 이름을 붙인다.** 네 가지를 섞지 않는다.
   - 오늘 **시간** %: 공부 시간 / 목표 시간 (도넛 가운데 "68% 시간")
   - 목표 **개수**: 끝낸 목표 / 오늘 목표 ("8개 중 3개", 통계 "목표 달성 · 개수")
   - **범위 진도**: 시험 범위 분량, 계획끼리는 **예상 공부 시간 비중**으로 합침
   - 그날 달성(캘린더 막대) = 목표 개수 기준
3. **빨강은 지금 행동이 필요한 한 곳에만.** 나머지는 회색 + 따라잡는 방법. (진도 탭: 인강 카드와 '늦어짐' 수만 빨강, 수학은 "예정보다 5쪽 뒤" 회색. 캘린더 75% 미만은 회색. 속도·예측 날짜도 먹색.)
   - **최소 목표**: 하루 10분 이상이면 연속 공부가 이어짐(더보기 '연속 공부 기준'). 연속 타일 "오늘 10분이면 8일째".
   - **새 주 시작**(RNewWeek): 월요일 오늘 탭 맨 위 카드. 지난주 결과·쌓은 것, 못 한 분량을 이번 주에 나눔, 이번 주 목표, 이번 주 시작.
4. **쌓인 것을 보여 준다.** 진도 탭 "11월에 쌓은 것"(쪽·문항·강·끝낸 단원). 진도 '끝낸 것' = **내 책장**(RProgDone: 끝낸 책은 색 책등, 진행 중은 채워지는 책등). 하루 최고 기록 갱신 표시.
5. (코드에서) 기록 마찰 줄이기: 한 번 눌러 "목표만큼 함", 기본값 = 오늘 목표, 빠진 날 몰아 넣기.
6. (코드에서) 실력 파악: 문제집 맞은/틀린 수 → 단원별 정답률, 이해도·오답·복습 → 시험 전 약한 단원.
7. (코드에서) 데이터 지키기: `navigator.storage.persist()`, 주 1회 백업 알림, 백업 파일 저장 위치 안내.
- 넣지 않는 것: 순위 경쟁, 배지 수집, 포인트.

## 6. 확정된 오늘 탭 (15번)

캔버스 '오늘 탭 새 시안' 페이지 맨 오른쪽. 윗줄 라이트 5장, 아랫줄 다크 5장.

- **상단 위젯 타일** (편집으로 넣고 빼고 순서 바꾸기)
  - 오늘 공부: 과목별 도넛 + 4:22 / 6:27 + 과목 범례
  - 남은 공부 2:05 + "지금 속도면 21:55 끝"
  - 시험 D-day: 반원 게이지 32% + 예정 위치 눈금 + "예정 34%보다 −2%p"
  - 최근 7일: 막대 + 합계
  - 연속 공부: 7일 + 점 12개 + 최고 기록
- **유형 탭**: iOS 세그먼트 `전체 · 책 · 인강 · 시간 · 습관 · 할 일`. 밀린 계획이 있는 탭에 빨간 점. 스크롤하면 날짜 + "오늘 4:22 / 6:27 · 68%" + 탭이 위에 고정.
- **전체 탭**: "오늘 목표 8개 중 3개 끝". 계획마다 3줄(이름·큰 %, 목표·밀림·한 양, 과목색 막대). 끝낸 것은 한 줄로 접음. 행을 누르면 해당 탭의 카드로 이동.
- **책 탭**: 오늘 쪽 칸 + 리본 책갈피, 책 전체 단원 막대 + 예정 눈금, **단원별 진행**(완료일·이해도·복습·예정일), 예상 끝나는 날. 문제집은 문항 동그라미 + 전체 막대.
- **인강 탭**: 재생 바, 30강 칸 + 이번 주 범위, **강의 목록**(끝난 날·진행 중·예정일).
- **시간 탭**: 10분 블록, **최근 7일 막대 + 목표 점선**, "목표를 채운 날 4일 / 7일".
- **습관 탭**: 습관(이번 달 칸 잔디, 연속 일수).
- **할 일 탭**: 오늘 할 일(체크박스, 마감) + 다가오는 할 일(이번 주, D-day).
- 마지막으로 본 탭을 기억. 위젯은 길게 눌러 편집.

## 6-1. 나머지 화면 (확인 대기)

캔버스 '나머지 화면 (15 언어)' 페이지. 윗줄 라이트 9장, 아랫줄 다크 9장. 생성 스크립트는 스크래치패드 `gen-rest.js`.

- **진도 탭** (RProg): 시험 카드(32%, 예정 34% 세로선, 시험 전 끝남·늦어짐·복습 수). 계획마다 단원으로 나뉜 막대 + 리본 + 예정선, "계획대로면 ○일 끝 · 시험 ○일 전". 늦어지는 계획에는 "하루 1강씩 들으면 12월 4일" 제안 + 계획 바꾸기. 복습할 단원(이해도 막대). `진행 중 · 끝낸 것` 세그먼트 아래 **유형 하위 탭** `전체 · 책 · 인강`(밑줄 탭, 개수, 늦어지는 유형에 빨간 점). 책과 문제집은 오늘 탭처럼 '책' 하나로 합침(앱 전체 분류 통일, 카드마다 자기 진행 그림은 유지). 문제집이 많아지면 그때 분리. 유형을 고르면 계획 카드와 복습 목록이 그 유형만 남음(RProgBook).
- **진도 자세히** (RDetail): 큰 진도 막대, 필요한 속도 vs 최근 7일 속도, 완료 예측 타임라인(오늘·계획·시험·지금 속도), 최근 14일 쪽 수 + 목표선, 단원 지도(기간·걸린 날·이해도·복습).
- **통계** (RStats): 이번 주·이번 달·시험까지. 과목별 누적 막대, 목표 달성 링, 한 번에 집중, 끝낸 단원, 연속, 과목 비중, 집중 시간대 히트맵, 계획별 이번 주.
- **캘린더** (RCal): 날짜 아래 달성 막대(75% 미만 빨강), 쉼, 단원 시작 점, 월 요약 3칸, 고른 날 계획 목록.
- **새 계획** (RNew): 종류 6개(책·목차, 문제집, 인강, 시간, 습관, 할 일)를 오늘 탭 진행 그림으로 보여 줌. 과목, 시험, 목차 붙여넣기, 기간·요일, 나누는 방식, 미리보기(하루 쪽 수, 단원 끝나는 날).
- **분량 입력** (REntry): 아래 시트. −/+ 큰 숫자, 쪽 칸 누르기 + 리본, 빠른 선택(오늘 목표, 단원 끝), 공부한 시간, 이해도(단원 끝낼 때), 한 줄 메모. 저장은 엄지 영역.
- **스톱워치** (RTimer): 10분 칸 9개 링(앞서 한 것 연하게, 지금 진하게), 시작 시각, 오늘 전체 막대, 멈춤·끝내기 큰 버튼, 화면 켜 둠.
- **더보기** (RMore): 계획 관리, 시험, 위젯 편집, 과목과 색, 공부 요일, 화면 모드(기기 설정·라이트·다크), 알림, 백업, 저장 위치 안내.
- **빈 상태** (REmpty): 첫날. 모르는 값은 0 대신 "—"와 설명, 시험 추가 점선 타일, 첫 계획 만들기.
- **쉬는 날** (RRest): 책갈피 끼운 책 그림 + "오늘은 쉬는 날", 쉬는 날 취소·옮긴 방법 바꾸기. 연속은 끊기지 않음. **내일로 옮긴 분량**(계획별 양과 옮긴 방법, 내일이 무거우면 "나눠서 옮기기" 제안). 쉬는 날에도 하는 습관.
- **통계 자세히** (RStatsMore): 최근 4주·12주·전체. 공부 잔디(12주), 요약 3칸, 요일별 평균, 목표 달성 추이(꺾은선 + 80% 목표선), 가장 오래 집중한 기록 5개, 언제 끝날까(계획대로 vs 지금 속도).
- **밀린 분량 정리** (RCatchup): 다음 날 오늘 탭을 열면 한 번 뜨는 시트. 어제 못 한 것 목록 → 계획마다 `남은 날에 나누기(추천) / 오늘 더하기 / 끝나는 날 늦추기`, 고르면 결과(하루 7 → 7.2쪽, 시험 당일 경고)를 바로 보여 줌. 할 일은 오늘로 옮기기 + 날짜 바꾸기. "다음부터 묻지 않고 남은 날에 나누기" 스위치.
- **스톱워치 미니 바** (RMiniTimer): 스톱워치를 내리고 다른 탭을 보면 하단 탭 위에 떠 있는 바(계획, 시간, 멈춤, 끝내기).
- **끝낸 뒤 기록** (RTimerEnd): 끝내기 → 시트 "48분 공부했어요", 10분 칸, 오늘 전체 변화, 계획(바꾸기 가능)의 어디까지 했나요(−/+, 쪽 칸), 한 줄 메모, `시간만 저장 / 저장`.
- **계획 편집** (RPlanEdit): 기간·요일, 남은 분량과 하루 분량, **날짜별 분량** 3주 달력(누르면 그날 분량 조절·쉬는 날로·원래대로, 줄인 만큼 다음 날들에 더함, 늘어난 날 빨간 밑줄), 멈추기·다 끝낸 것으로·지우기.
- **지난 기록 고치기** (RHistEdit): 캘린더에서 날짜 → 그날 요약 3칸, 계획 기록 고치기(쪽, 공부 시간 목록, 시간 직접 넣기, 지우기). 고치면 오늘부터 남은 분량이 다시 나뉜다는 안내와 결과.
- **단원을 끝냈을 때** (RDoneChapter): 분량 입력으로 단원 마지막 쪽에 닿으면 시트. 책갈피 끼운 책 그림 + "3단원을 끝냈어요", 걸린 날(예정 대비)·공부 시간·단원 수, 리본이 다음 단원으로 넘어간 막대, **이해도 상·중·하**(설명 포함, 고르면 복습 날짜 안내), 다음 단원, "저장하고 이어서". 과장된 축하 효과 없음.
- **오늘 목표를 다 했을 때** (RDoneDay): 도넛 가운데 체크 + "목표를 다 채웠어요", 연속 일수 카드(점, 최고 기록까지 남은 날) + 하루 마무리 보기·내일 미리 보기, 목록은 모두 100%.
- **하루 마무리** (RDayEnd): 밤에 한 장 요약. 도넛 94% + 끝낸 목표·연속·가장 긴 집중·어제보다, **언제 공부했나** 하루 타임라인(6시~24시, 과목색), 오늘 한 것(못 한 건 "내일로"), 오늘 남긴 메모(단원 자세히에도 남음), 내일 첫 공부 + 오늘은 끝.
- **계획 관리** (RPlans): 진행 중·멈춘 것·끝낸 것. 5가지 분류로 묶음(책, 인강, 시간, 습관, 할 일). 새 계획도 같은 5가지 + 책은 `목차(쪽) · 문제집(문항) · 분량만`으로 나누는 방식 선택.
- **시험 설정** (RExam): D-day, 이름·날짜·비워 둘 날(시험 전 복습만 하는 날), **시험 범위**(계획 체크 + 범위, 남은 양; 시간 계획은 범위 없음), "끝나는 날을 12월 9일로 맞추기" 스위치와 계획별 바뀌는 날짜·하루 공부량 변화, 시험 지우기. 데이터: 시험 ↔ 계획(범위) 연결.
- **위젯 편집** (RWidgetEdit): 지금 위젯(− 빼기, 넓게·작게, 길게 눌러 옮기기, 최대 8개) + 더할 수 있는 위젯 6개(과목 비중, 다음 복습, 이번 주 목표, 내일 미리 보기, 오늘 메모, 바로 시작). 점 여섯 개로 순서 바꾸기, 왼쪽으로 밀면 멈춤·끝냄.

## 11. 새 계획 개편 방향 (2026-11-22 논의, 시안 전)

학습 관점 검토 결과: 지금은 종료일까지 꽉 채워 쪽 수로 똑같이 나누고, 1회독으로 끝나며, 목차는 한 단계뿐이다. 계획 오류(시간을 적게 잡음)에 버퍼가 없고, 단원 난이도·요일별 여유를 반영하지 못한다.

사용자가 정한 것:
- 공부 상황: 시험 공부와 꾸준한 공부가 **섞여 있음**. 시험 기능과 반복 계획 모두 유지.
- **과목**: 새 계획 화면에서 바로 `+ 과목`(이름·색). 색은 5가지에서 8~10가지로 늘림.
- **목차**: 깊이 자유(들여쓰기만큼). 쪽은 가장 아래 항목의 시작 쪽만 입력하고 끝 쪽은 자동(다음 항목 시작 − 1, 마지막만 끝 쪽). 입력은 한 줄씩 추가하는 목록(들여쓰기·내어쓰기, 손잡이로 순서) + 통째로 붙여넣기(들여쓰기·`-`로 깊이 읽기).
- **하루 분량은 가장 아래 항목 끝에서 끊음.** 진도 그림·이해도·복습은 맨 위 단원으로 묶어 보여 줌.
- **예비일**: 요일을 공부 / 예비 / 쉼 세 가지로 고름. 그 주에 밀린 분량을 예비일에 처리(엔진의 `supplementDow` 활용), **밀린 게 없으면 복습을 넣어 줌**(이해도 낮은 단원, 복습할 때가 된 단원).
- **끝 버퍼**: 종료일 전 며칠은 분량 없이 비워 둠(시험 '비워 둘 날'과 같은 원리).
- 버퍼 기본값: **주 1회 예비일(일요일) + 끝 2일**, 새 계획에서 바꿀 수 있음.
- **나누는 기준: 단원 무게 + 요일별 공부 가능 시간 둘 다.** 단원마다 쉬움·보통·어려움(기본 보통), 공부를 시작하면 실제 속도로 보정(`secPerUnit`).
- **요일별 공부 가능 시간은 앱 전체에 한 번**(더보기). 모든 계획이 그 비율로 하루 분량을 나눔.
- **회독**(1회독 → 2회독 → 오답만)은 이번에 데이터 모델을 같이 설계. 구현은 나중이어도 됨.
- **가능 시간을 넘는 날은 자동으로 나눠 담음**(경고만 하는 안 대신). 계획들이 앱 전체 가능 시간을 나눠 쓰는 배분이 된다. 함께 지킬 것(제안):
  - 옮기는 순서: 마감(종료일·시험)이 먼 계획, 여유가 큰 계획부터 옮김. 마감이 가까운 계획은 자리를 지킴.
  - 옮겨도 안 들어가면 종료일이 밀린다고 알리고, 시험 뒤로 밀리면 빨강(행동이 필요한 곳).
  - 바뀐 것을 늘 보여 줌: 새 계획 미리보기에 "이 계획 때문에 쎈 수학 토요일 15→10문항", 오늘 탭·계획 편집에 "가능 시간에 맞춰 옮김" 표시.
  - 직접 정한 날 분량(`custom`)과 지난 날은 옮기지 않음.

2차 논의(시안 NP* 6장을 본 뒤):
- **간단하게 / 자세히 두 갈래**로 접근(기능은 유지). 제안: 처음엔 이름·범위·끝나는 날만 받는 빠른 계획이 기본이고, 나머지는 기본값(일요일 예비, 끝 2일, 무게 보통)으로 처리. "자세히 정하기"는 같은 화면 아래 또는 만든 뒤 언제든.
- **과목은 처음에 비어 있음**. 이름·색을 자유롭게 추가하고, 프리셋(고등 내신·수능·공무원·자격증 등)과 예전에 쓴 과목에서 쉽게 가져옴. 과목 없이도 계획을 만들 수 있음.
- 목차 붙여넣기 검토 제안: 웹·PDF에서 복사하면 들여쓰기가 사라지므로 **번호 모양으로 깊이를 읽음**(Ⅰ → 1. → (1) → ① 순서, 처음 나온 순서대로 단계 배정), 점선(·····)과 끝 쪽 번호 처리, 쪽이 없는 줄도 받음, 읽은 결과에서 줄마다 단계 ←/→ 고치기.
- 인지과학 검토 제안(확인 전): 이해도는 단원 직후가 아니라 하루 뒤나 복습 때 묻기(직후 판단은 부풀려짐), 자기평가와 문제 정답률 비교, 2회독은 다시 읽기가 아니라 인출(덮고 떠올리기·문제) 중심, 회독·가능 시간은 처음에 묻지 않고 필요할 때 제안(1회독 끝날 때, 기록이 쌓였을 때), 위치는 %p보다 "여유 ○일"로.

  - **익숙한 그림으로 확정(2026-11-23, 사용자 '추천대로')**: 넘치는 날 = **A 시계**("계획대로면 밤 11시 10분에 끝나요 · 평소엔 10시까지", 시간 줄에서 넘친 부분만 먹색, 버튼 하나 '밤 11시 30분까지 하기' + '다른 방법' 시트), 여유 = **E 디데이 목록**(왼쪽 큰 칸 '여유 n일', 누르면 D 달력). 하루 상자·책갈피 길·막대·빗금은 폐기. 앱 구현: `src/Guide.tsx`(OverCard·SlackCard·SuggestCard), 오늘 탭 안내 카드는 한 번에 한 장(넘치는 날 → 회독 → 제안), 제안은 하루 한 장(`settings.suggested`). 해결: 그날만 시간대 늘리기(`settings.windowOverrides`), 마감 먼 계획 그날만 줄이기(custom), 마감 가까운 계획 끝나는 날 늦추기(시험 뒤면 빨강), 오늘은 그대로(`overSnooze`). 제안 4가지: 단원 다음 날 떠올리기 → 이해도, 첫 주 속도 → 끝나는 날 늦추기/지키기, 정답률 70% 미만인데 '잘 앎' 단원 → 복습 넣기(이해도 중으로), 최근 4주 요일별 기록 → 공부 가능 시간 바꾸기. 개발용 장면 `?demo=tight`.
  - **학습 위젯(2026-11-23, 사용자 확정 A+C)**: 칸 격자(작게 1×1 · 넓게 2×1 · 크게 2×2, 칸 = 반 너비 × 164px, 빈칸은 작은 위젯이 채움), 위젯마다 맞는 크기만(`WIDGET_SIZES`). 핵심 6개: 오늘 진행 · 오늘 복습 · 시험까지 여유 · 떠올리기 · 다시 풀 문항 · 이해도 지도(`src/LearnWidgets.tsx`). 색 = A+C: 한 과목 위젯은 과목색 틴트(15%), 오늘 진행 크게는 먹색 주인공, 라벨 앞 아이콘 칩. 기본 = 오늘 진행 크게 · 오늘 복습 · 시험까지 여유 · 떠올리기 넓게(예전 기본 구성을 그대로 쓰던 사람만 새 기본으로). 개수 제한 없음. 편집은 One UI 방식(흔들림 없음, 길게 눌러 1.04배로 들어 올려 손가락을 따라 이동, 다른 위젯은 미끄러지듯 비킴, 누르면 크기 칩). 누르면 시트: 오늘 진행(공부한 때 + 계획별), 오늘 복습('복습했어요'), 시험까지 여유(목록 → 달력), 이해도 지도(단원별 고르기). 예전 위젯 10개는 그대로 골라 넣기(크기 고정). (2026-11-23 2차) 끌어 옮기기 흔들림 고침: 다른 위젯 가운데 60%에 들어와야 바꾸고, 방금 바꾼 위젯은 손가락이 벗어난 뒤에만 다시(180ms), 들고 있는 위젯은 레이아웃 직후 바로 손가락 자리로, 비키는 움직임은 이동만·튕김 없이 0.24초. 위젯 16종 모두 누르면 자세히 시트(`src/WSheet.tsx`, One UI: 큰 숫자 + 묶음 카드). 예전 위젯 10종은 새 칸 디자인으로(`src/MoreWidgets.tsx`), 넓게를 고를 수 있는 것: 오늘 공부 시간·최근 7일·연속 공부·과목 비중·내일·메모. **스마트 스택**(`stack`, items): 한 칸에 여러 장, 옆으로 넘기고 오른쪽 점, 아침엔 오늘 진행·시험, 낮엔 진행·복습, 밤 8시 뒤엔 떠올리기·내일이 앞에. 편집에서 스택을 누르면 겹칠 위젯 고르기.
제안했지만 아직 안 정한 것: 계획을 세우는 출발점 3가지(끝나는 날 / 하루 분량 / 하루 시간), 하루 상한 경고, 앞쪽에 몰기, 최소 목표("바쁜 날엔 이것만"), 시험에서 거꾸로 계획, 계획 복사·템플릿, 인강도 같은 목차 구조로.

화면 원칙: 기본 화면은 이름·과목·목차·기간만. 예비일·단원 무게·회독은 "자세히" 아래 접고 기본값으로 대부분 해결. 미리보기에 결과를 바로("예비일 4일 · 하루 7쪽 · 12월 9일 끝 · 시험 3일 전", 가능 시간을 넘는 요일 경고).
